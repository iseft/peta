# Peta

Personal Expense Tracking Application: plan your money, see where it really goes, keep to 50/30/20.

- `apps/api`: NestJS API
- `apps/mobile`: Expo (Android first) app
- `apps/web`: marketing site and legal pages
- `packages/shared`: DTOs shared by the API and the app

Start with `CLAUDE.md` (commands, architecture), `docs/mvp-spec.md` (scope) and `GLOSSARY.md` (vocabulary).
